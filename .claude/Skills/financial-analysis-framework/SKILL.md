# 財務與市場分析技能

這份技能提供「判讀財報與市場資料」的具體框架，分成三部分：財務指標判讀、產業競爭格局分析、輸出規範。

## 一、財務指標判讀

| 指標類別 | 關鍵指標 | 解讀重點 |
|---|---|---|
| 獲利能力 | 營收成長率、毛利率、淨利率 | 跟同業比較才有意義，單看趨勢方向（成長/衰退）比單一數字更重要 |
| 財務健康度 | 負債比率、流動比率、現金流量 | 現金流是否為正比帳面獲利更能反映實際營運狀況 |
| 營運效率 | 存貨週轉率、應收帳款週轉天數 | 反映營運管理效率，數字異常變化需留意原因 |
| 估值參考 | 本益比、股價淨值比 | 僅為參考指標，需搭配產業特性判讀，不同產業合理區間差異大 |

**重要提醒**：任何單一指標都不該單獨下結論，務必搭配（1）同業比較（2）歷史趨勢（3）總體經濟環境三個維度交叉檢視。

## 二、產業競爭格局分析框架

1. **市場地位**：市佔率、成長速度相對同業快慢
2. **競爭優勢來源**：成本優勢、技術/專利壁壘、品牌/通路優勢、規模經濟
3. **產業結構**：進入門檻高低、供應商/客戶議價能力、替代品威脅、既有競爭者激烈程度（簡化版五力分析）
4. **趨勢位置**：處於產業生命週期的哪個階段（成長期/成熟期/衰退期），影響策略解讀的合理性

## 三、總體經濟數據解讀原則

- 單一總經數據（如 GDP、CPI）需搭配時間序列（跟前期比較）與跨國比較才有意義
- 避免用單一月份或單一季度的數據做長期趨勢判斷，注意數據的季節性調整與否
- 區分「已公布的官方數據」與「機構預測/推估數據」，兩者可信度層級不同

## 四、輸出規範（務必遵守）

1. **事實與推測分離**：財報數字、公開統計是事實；「這代表公司會如何」是推測，語氣需明確區分
2. **時效性標註**：所有數據都要附上擷取或發布時間點
3. **不做投資建議**：只呈現分析依據，不給「買進/賣出/持有」的結論性建議，並在報告結尾聲明僅供參考
4. **不做確定性預測**：未來走勢只能呈現可能情境與其依據，不能用肯定語氣斷言

## 五、輸出前檢查清單

- [ ] 財務指標是否已跟同業或歷史趨勢對照，而非單獨呈現
- [ ] 所有數據是否標註時間點與來源
- [ ] 是否清楚區分「事實數據」與「推測/解讀」的語氣
- [ ] 是否避免了任何形式的投資決策建議，並附上「僅供參考」聲明
