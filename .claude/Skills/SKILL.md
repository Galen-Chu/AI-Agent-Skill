# 講稿結構技能

這份技能提供「書面轉口語」的具體規則，分成三部分：句式調整、講稿結構慣例、常見錯誤。

## 一、句式調整規則

1. **長句拆短句**：書面語常見一句話包含多個子句，口語表達時一口氣念不完，拆成 2-3 個短句
2. **書面語換口語詞**：例如「藉由」→「透過」、「此外」→「另外」、「上述」→「剛剛講的」，降低唸出來的生硬感
3. **善用停頓標註**：語意轉折、重點強調處，用 `（停頓）` 或 `／` 標註，提示講者放慢或停頓
4. **避免密集數字/專有名詞堆疊**：書面稿可以一次列出多個數據，口語稿建議一次講一個重點，數據間留出呼吸空間

## 二、講稿結構慣例

- **開場**：簡短破題，不要照搬簡報標題直接念，用一句話帶出「為什麼聽眾該關心這個」
- **主體**：依原始內容的段落順序展開，每段之間加入清楚的過渡語句（例如「接下來看第二點」），幫助聽眾跟上節奏
- **結尾**：總結核心訊息 + 明確的行動呼籲或收尾語句，不要突然結束

## 三、常見錯誤與避免方式

1. **直接照搬書面稿**：書面稿的句式念出來會很拗口，務必依上述規則轉換，不是換個標題就叫講稿
2. **句子過長導致換氣困難**：檢查每句話是否能一口氣自然念完，過長就拆句
3. **省略過渡語句**：段落間直接跳轉會讓聽眾跟不上邏輯，每個轉折都要有明確的口語橋接
4. **忽略停頓與強調**：全文平鋪直敘沒有停頓標註，講者唸起來容易語速過快、重點不突出

## 四、輸出前檢查清單

- [ ] 是否已將長句拆解成適合口語的短句
- [ ] 書面用語是否已轉換為口語用詞
- [ ] 段落間是否有清楚的過渡語句
- [ ] 開場是否破題而非直接照搬標題，結尾是否有明確收尾
- [ ] 重點/轉折處是否已標註停頓
