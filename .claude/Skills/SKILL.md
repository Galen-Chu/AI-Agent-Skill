# 學術引用審查技能

這份技能提供「評估學術研究可信度」的具體框架，分成三部分：引用鏈追溯、方法論嚴謹度評估、共識程度分級。

## 一、引用鏈追溯方法

1. **區分一手與二手來源**：原始論文/研究是一手來源；新聞報導、部落格文章轉述研究結果是二手來源，可信度依附於是否忠實呈現原始研究
2. **追溯到最初研究**：媒體常見「研究顯示……」卻未附連結，遇到這種情況要嘗試找出被引用的原始論文，而非直接採信轉述內容
3. **檢查是否斷章取義**：原始研究的結論常有限定條件（樣本範圍、適用情境），轉述時若省略限定條件，會誇大或扭曲原始發現，需特別標註

## 二、方法論嚴謹度評估標準

| 面向 | 檢視重點 |
|---|---|
| 樣本 | 樣本量是否足夠、樣本是否具代表性（而非特定族群無法推論到一般情況） |
| 研究設計 | 是否有對照組、是否為隨機對照試驗（RCT）或觀察性研究（因果推論強度不同） |
| 統計方法 | 使用的統計方法是否適合研究問題、有無過度解讀相關性為因果關係 |
| 同行評審 | 是否發表於經同行評審的期刊，或僅為預印本（preprint，尚未經審查） |
| 利益揭露 | 是否揭露資金來源與潛在利益衝突 |
| 自陳限制 | 研究者本身是否誠實列出研究限制，這通常是嚴謹研究的正面訊號 |

## 三、學術共識程度分級

評估完成後，依證據強度分級呈現，不可都用同樣篤定的語氣描述：

1. **單一研究初步證據**：僅一篇研究支持，尚待重複驗證
2. **多篇獨立研究一致**：多個不同研究團隊、不同樣本得出一致結論
3. **系統性回顧／統合分析支持**：已有整合多篇研究的系統性回顧或 meta-analysis 支持該結論，證據強度最高
4. **尚有爭議、未有共識**：不同研究結果互相矛盾，或領域內仍在辯論中，應如實呈現爭議雙方的論點與依據

## 四、引用格式與版權規範（務必遵守）

1. **格式**：作者/機構（年份）。研究標題或簡述。連結——每個實質性主張後都要能對應到這份清單裡的項目
2. **內容一律改寫**：研究發現、方法、結論都用自己的話重新表達，不逐段複製摘要
3. **極簡短引用限制**：僅在原始措辭具有精確定義上的意義時（例如法律/醫學術語的官方定義），可保留 15 字以內的直接引用，且同一來源全篇僅能引用一次
4. **不省略反面證據**：若查證過程中發現與主流結論相左的研究，也應一併呈現，不能只挑支持某個立場的來源

## 五、輸出前檢查清單

- [ ] 每個實質性主張都能對應到參考來源清單中的項目
- [ ] 已區分一手研究與二手轉述，並註明追溯結果
- [ ] 方法論評估有具體依據，非籠統評語
- [ ] 已標註學術共識程度分級，語氣強度與證據強度相符
- [ ] 內容為改寫而非逐字複製，引用符合簡短限制
