# 來源可靠度評估技能

這份技能提供「判斷資訊可不可信」的具體框架，分成三部分：來源信譽標準、交叉查證方法、常見不實資訊模式。

## 一、來源信譽標準

檢視以下面向，非單一項目就能定生死，而是綜合判斷：

| 面向 | 高信譽特徵 | 低信譽警訊 |
|---|---|---|
| 發布單位 | 有明確組織、可查證的營運記錄 | 匿名、新註冊網域、無法查證身分 |
| 作者揭露 | 具名作者、可查證專業背景 | 無署名、或署名但查無此人 |
| 更正機制 | 有公開更正/勘誤紀錄 | 從無更正紀錄（可能代表從不檢視錯誤，也可能代表從未犯錯，需搭配其他指標判斷） |
| 利益揭露 | 明確標示業配/贊助內容 | 業配內容偽裝成一般報導或評論 |
| 引用習慣 | 引用原始資料/官方來源 | 只引用其他二手報導，追溯不到源頭 |

## 二、交叉查證方法

1. **找獨立來源**：至少找 2-3 個彼此沒有互相轉載關係的來源，確認是否報導一致
2. **追溯到源頭**：多個媒體報導同一件事時，嘗試找出最初的原始來源（官方公告、當事人聲明、原始研究），二手轉載的可信度依附於源頭的可信度
3. **查核機構比對**：若話題具爭議性，查詢是否已有事實查核機構（如國內外主流查核組織）發布相關查核結果
4. **時間序一致性**：檢查事件發展時間軸是否合理，是否有時間錯置（如用舊照片配新聞）的情況

## 三、常見不實資訊辨識模式

- **情緒化標題與內文不符**：標題聳動但內文證據薄弱或無關
- **斷章取義**：引用片段脫離原始脈絡，改變原意
- **偽造權威**：假借專家/機構名義但查無實據
- **時間或數據錯置**：舊事新傳、統計數字脫離原始脈絡誤用
- **同溫層放大**：僅在特定立場社群大量轉傳，主流查證機構或跨立場來源均未提及

## 四、政治中立處理原則

遇到政治或社會爭議議題時：
- 只評估**事實查證層面**（數據是否準確、引述是否符合原意、來源是否可靠），不對議題立場本身表態
- 若不同立場的來源對同一事件有不同描述，如實呈現雙方說法與各自依據，不代替使用者選邊
- 避免使用帶有立場暗示的形容詞描述任一方

## 五、輸出前檢查清單

- [ ] 是否至少交叉比對了 2 個以上獨立來源
- [ ] 評估依據是否具體可查證，而非僅憑直覺
- [ ] 若為爭議性話題，是否維持事實查證中立、未對立場表態
- [ ] 證據不足時是否誠實標註「不確定」，而非勉強給結論
